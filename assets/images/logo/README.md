# Logo

`artemis-logo.png` is the Artemis logo used on the login screen (light and dark mode).

To update it, replace the file and keep the same name. Use a transparent PNG at least
512px on its longest side. It's drawn in a 144×144 box and scaled to fit
(`contentFit="contain"`). After replacing it, reload the app (press `r` in the Expo terminal).
